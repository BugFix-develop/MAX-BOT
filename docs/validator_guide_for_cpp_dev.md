## 1. Введение: Зачем валидатор в чат-боте?

Когда школьник решает задачу, например $(x + 2)^2 = x^2 + 4x + 4$, он может отправить в чат бота ответ в десятках разных вариаций:
* `x^2 + 4x + 4`
* `x**2 + 4*x + 4` (в стиле языка программирования)
* `х^2 + 4х + 4` (внимание: буква `х` набрана на **русской раскладке клавиатуры**!)
* `x во 2 + 4x + 4`
* `x в квадрате + 4x + 4`
* `  X ^ 2 +  4 X + 4  ` (куча пробелов и заглавная буква)

Если делать наивное сравнение `if user_answer == expected_answer:`, бот будет постоянно ругать ученика за пробел или русскую раскладку.

Задача **Валидатора** — привести обе строки к единому **каноническому (нормализованному) виду** перед тем, как сравнивать.

```
       "  х в квадрате + 4*Х + 4 "
                 │
                 ▼  normalize_answer()
            "x^2+4x+4"
                 │
                 ▼  Сравнение с эталоном
             (True, "Верно!")
```

## 2. Базовые операции со строками в Python (vs C++)

Строки `str` в Python — **неизменяемые (immutable)**. Любая операция не меняет исходную строку «на месте», а возвращает **новую строку** (как `QString` в большинстве методов).

| Действие | C++ (`std::string` / Qt `QString`) | Python (`str`) | Что делает |
| :--- | :--- | :--- | :--- |
| **Нижний регистр** | `str = str.toLower();` (Qt) / `std::tolower` | `s = s.lower()` | Переводит все буквы в строчные |
| **Удаление пробелов по краям** | `str = str.trimmed();` | `s = s.strip()` | Убирает `\t`, `\n`, пробелы с концов |
| **Замена подстроки** | `str.replace("a", "b");` | `s = s.replace("a", "b")` | Заменяет все вхождения `a` на `b` |
| **Удаление всех пробелов** | `str.remove(' ');` | `s = s.replace(" ", "")` | Убирает вообще все пробелы из строки |

## 3. Массовая замена символов: Кириллица $\to$ Латиница

В C++ для замены набора символов обычно запускают цикл по `std::map<char, char>`.
В Python для этого есть супер-быстрый встроенный инструмент — метод **`translate()`** и таблица преобразования **`str.maketrans()`**:

```python
# Создаем таблицу соответствий (символ слева меняется на символ справа)
# Русские буквы 'а', 'с', 'е', 'о', 'р', 'х', 'у' -> английские аналоги:
CYRILLIC_TO_LATIN = str.maketrans({
    "а": "a",
    "в": "b",
    "с": "c",
    "е": "e",
    "о": "o",
    "р": "p",
    "х": "x",
    "у": "y",
})

# Применение:
user_text = "4х + 2у"  # здесь 'х' и 'у' русские
clean_text = user_text.translate(CYRILLIC_TO_LATIN)
# clean_text теперь "4x + 2y" (буквы стали латинскими ASCII)
```

## 4. Модуль `re` (Регулярные выражения в Python)

В C++ ты использовал `std::regex` или `QRegularExpression`.
В Python стандартный модуль называется **`re`** (`import re`).

### 4.1. Сырые строки: префикс `r"..."`
В регулярках часто встречается обратный слэш `\`.
* Обычная строка `"\\d"` требует экранирования самого слэша.
* В Python всегда используй **raw-строки** с буквой `r` перед кавычками: `r"\d+"`. В таких строках слэш не экранируется (как `R"(...)"` в C++11).

---

### 4.2. Главная функция для нормализации: `re.sub()`

`re.sub(pattern, replacement, string, flags=0)`
* `pattern`: регулярное выражение (шаблон поиска).
* `replacement`: на что заменить найденное.
* `string`: исходный текст.
* `flags`: флаги (например, `re.IGNORECASE` — не учитывать регистр).

#### Аналогия:
* **Qt:** `str.replace(QRegularExpression(pattern), replacement);`
* **Python:** `new_str = re.sub(pattern, replacement, str)`

---

### 4.3. Примеры шаблонов `re.sub`

#### 1) Замена степеней (квадратов):
Школьник может написать:
- `x^2`
- `x**2` (Python-стиль)
- `x во 2`
- `x во второй`
- `x в квадрате`
- `x²` (юникод-символ квадрата!)

Как превратить их все в стандартное `^2`?

```python
import re

text = "x**2 + y во 2 + z в квадрате + a²"

# 1. Заменяем **2 на ^2
text = text.replace("**2", "^2")

# 2. Заменяем юникодную двойку ² на ^2
text = text.replace("²", "^2")

# 3. Регулярка для словесных конструкций:
# r"\s*(в\s*квадрате|во\s*2|во\s*второй|в\s*степени\s*2)" -> меняем на "^2"
pattern_square = r"\s*(в\s*квадрате|во\s*2|во\s*второй|в\s*степени\s*2)"
text = re.sub(pattern_square, "^2", text)

print(text)
# Результат: "x^2 + y^2 + z^2 + a^2"
```

#### 2) Замена кубов (степени 3):
Аналогично для кубов:
* `x**3` $\to$ `x^3`
* `x³` $\to$ `x^3`
* `в кубе`, `в 3`, `в третьей`, `в степени 3` $\to$ `^3`

```python
pattern_cube = r"\s*(в\s*кубе|в\s*3|в\s*третьей|в\s*степени\s*3)"
text = re.sub(pattern_cube, "^3", text)
```

#### 3) Удаление знаков умножения `*` между числом и переменной:
Школьник может ввести `4*x`, а эталон — `4x`:
```python
# Заменяем '*' на пустую строку, ЕСЛИ это умножение
# Но проще в нормализации просто удалить все '*':
text = text.replace("*", "")
# "4*x*y" -> "4xy"
```

## 5. Кортежи `tuple` в Python (vs `std::pair` / `std::tuple`)

По ТЗ функция проверки ответа имеет сигнатуру:
```python
def check_answer(user_input: str, expected_answer: str) -> tuple[bool, str]:
```

Что такое `tuple[bool, str]`?
* В **C++**: это `std::pair<bool, std::string>` или `std::tuple<bool, std::string>`.
* В **Python**: это кортеж из двух значений в круглых скобках: `(True, "Сообщение")`.

### Как это возвращать:
```python
# Если правильно:
return (True, "Верно! Отличная работа.")

# Если ошибка:
return (False, f"Неверно. Правильный ответ: {expected_answer}")
```

### Как вызывающий код это распаковывает:
```python
is_correct, message = check_answer(user_answer, task_expected)
if is_correct:
    print("Ура:", message)
else:
    print("Ошибка:", message)
```

## 6. Рекомендуемая архитектура `core/validator.py`

Вот каркас, по которому удобно выстроить твой файл:

```python
import re

# 1. Таблица транслитерации для похожих букв (русский -> английский)
REPLACE_CHARS = str.maketrans({
    "а": "a",
    "в": "b",
    "с": "c",
    "е": "e",
    "о": "o",
    "р": "p",
    "х": "x",
    "у": "y",
})

def normalize_answer(raw_answer: str) -> str:
    """
    Приводит строку к единому стандарту:
    - нижний регистр
    - замена похожих русских букв на латиницу
    - замена текстовых степеней (в квадрате, во 2, в кубе) на ^2 и ^3
    - удаление всех пробелов
    - удаление лишних знаков умножения (*)
    """
    if not raw_answer:
        return ""

    # Шаг 1: переводим в нижний регистр
    # ...

    # Шаг 2: заменяем кириллицу на латиницу через .translate()
    # ...

    # Шаг 3: заменяем текстовые степени через re.sub / replace
    # ...

    # Шаг 4: удаляем пробелы и знаки умножения
    # ...

    return text


def check_answer(user_input: str, expected_answer: str) -> tuple[bool, str]:
    """
    Сравнивает нормализованный ответ пользователя с нормализованным эталоном.
    Возвращает (is_correct, message).
    """
    # 1. Нормализуем оба ответа
    norm_user = normalize_answer(user_input)
    norm_expected = normalize_answer(expected_answer)

    # 2. Сравниваем строки
    if norm_user == norm_expected:
        return (True, "Верно! Молодец!")
    else:
        return (False, f"Неверно. Правильный ответ: {expected_answer}")
```

## 7. Как протестировать свой валидатор

После того как напишешь код в [core/validator.py](file:///home/muslim/Coding/Bot%20MAX/core/validator.py), в самом низу файла можно временно добавить блок самопроверки:

```python
if __name__ == "__main__":
    test_cases = [
        ("х^2 + 4х + 4", "x^2 + 4x + 4"),         # русская 'х'
        ("x**2 + 4*x + 4", "x^2 + 4x + 4"),       # питоновские ** и *
        ("x во 2 + 4x + 4", "x^2 + 4x + 4"),      # слова "во 2"
        ("x в квадрате + 4x + 4", "x^2 + 4x + 4"),# слова "в квадрате"
        ("X^2 + 4X + 4", "x^2 + 4x + 4"),         # заглавные буквы
    ]

    for user_ans, expected in test_cases:
        ok, msg = check_answer(user_ans, expected)
        status = "✅ OK" if ok else "❌ FAIL"
        print(f"{status} | '{user_ans}' -> {msg}")
```

Запустить проверку в терминале:
```bash
python3 core/validator.py
```
Если везде будут зеленые галочки `✅ OK` — задача выполнена идеально!
