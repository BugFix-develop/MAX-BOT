# Образовательная платформа «Тренажёр ФСУ» для MAX Messenger

Интеллектуальный образовательный сервис для школьников 7 класса и учителей математики в мессенджере **MAX**.  
Проект разработан в рамках всероссийского хакатона **«Образовательные решения»** (Минобрнауки России / MAX / VK).

* **Чат-бот в MAX:** `@t594_hakaton_max_bot` («Хакатон МАХ 594»)
* **Репозиторий:** `git@github.com:BugFix-develop/MAX-BOT.git` (ветка `step7`)
* **Стек технологий:** Python 3.11+, SQLite3, REST API (ThreadingHTTPServer), Vanilla JS / Modern CSS, Docker, Pytest

---

## 🎯 Назначение и ценность решения

Сервис решает ключевую образовательную задачу 7 класса — автоматизацию навыка применения **30 формул сокращённого умножения (ФСУ)**, избавляя учеников от страха перед алгеброй, а учителям экономя до 3 часов на подготовке к каждому уроку.

### 🌟 Два формата взаимодействия:
1. **Нативный чат-бот в MAX:** Быстрое решение задач в переписке, нативные кнопки меню, автоматический старт при открытии диалога, текстовые команды.
2. **Интерактивное веб-приложение (MAX Mini App):** Полноценный визуальный тренажёр прямо внутри мессенджера (команда `/app`) со специализированной математической клавиатурой, каталогом формул и конструктором уроков.

## 🚀 Ключевые возможности

### 1. Генератор задач по 30 формулам сокращённого умножения
* Полный охват школьной программы 7 класса:
  * Разность квадратов: базовые, зеркальные, с коэффициентами при $x$ и двумя переменными;
  * Квадрат суммы и разности: стандартные, с коэффициентами, многочлены;
  * Куб суммы и разности;
  * Сумма и разность кубов.
* Динамическая генерация случайных коэффициентов с гарантией уникальности задач для каждого ученика (исключение повторов через историю в SQLite).

### 2. Интеллектуальный математический валидатор
* Понимает и корректно валидирует **любые формы ввода**:
  * Верхний индекс: `x² - 16`, `(a + b)²`;
  * Символ степени: `x^2 - 16`;
  * Сокращённый ввод без знака степени: `x2 - 16` автоматически распознаётся как $x^2 - 16$;
  * Python-синтаксис: `x**2 - 16`;
  * Текстовая запись: `x в квадрате - 16`, `во 2 степени`;
  * Автозамена опечаток русской раскладки клавиатуры: русская `х` автоматически конвертируется в латинскую `x`, `а` → `a`, `в` → `b`, `с` → `c`;
  * Устойчивость к пробелам и знакам умножения (`4x`, `4*x`, `4 · x`).

### 3. Автоматическое форматирование в верхний индекс (`x²`)
* В интерфейсе Mini App реализован ввод математических степеней на лету: при вводе `^2` или `x2` символы сразу визуализируются как аккуратный типографический верхний индекс `x²`.
* Уравнения на смартфонах не разрываются посреди скобок благодаря адаптивному CSS-масштабированию (`clamp`) и защите от нежелательных переносов.

### 4. Дизайн-система без шаблонов ИИ (Human-Crafted Flat UI)
* Строгая академическая палитра: глубокий тёмно-фиолетовый (`#382054`), спокойный фон бумаги (`#F6F7F9`), чистые белые карточки.
* Полный отказ от размытых неоновых теней в пользу чёткой архитектурной сетки (`1px solid #D8DCE3`).
* Современная типографика: гуманитарный гротеск **Manrope** + моноширинный **JetBrains Mono** для математических формул.
* Аккуратные компактные скругления (4–8px) вместо гигантских овальных пузырей.

### 5. Методический блок для учителя
* **План урока на 45 минут по ФГОС:** Тайминг, цели, устная разминка (таблица квадратов), теория, практика у доски, дифференцированная самостоятельная работа и ДЗ.
* **Генератор контрольного варианта:** 15 разноуровневых задач по трём блокам тем с готовым ключом ответов для быстрой проверки.
* Кнопка мгновенного копирования готового конспекта в буфер обмена.

### 6. Геймификация и аналитика
* Счётчик непрерывной серии правильных ответов (Streak).
* Графический прогресс-бар курса (30 формул).
* Градация уровней мастерства: **Ученик → Практик → Эксперт курса**.
* Детализированная история последних решений с подсветкой статуса.

## 🔌 REST API веб-приложения

Сервер мини-приложения (`webapp_server.py`) предоставляет документированный JSON REST API:

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/health` | Healthcheck проверки работоспособности сервиса |
| `GET` | `/api/task` | Получить новую задачу (`user_id`, опционально `template_id`) |
| `POST` | `/api/check` | Проверить ответ ученика (`user_id`, `task_id`, `user_answer`, `expected_answer`) |
| `GET` | `/api/stats` | Получить статистику ученика (решено, точность, стрик, история) |
| `POST` | `/api/lesson` | Сгенерировать план урока (`plan_45min`) или проверочный вариант (`variant_15tasks`) |
| `GET` | `/api/templates`| Получить каталог всех 30 формул сокращённого умножения |

## 💻 Локальный запуск без Docker

### 1. Подготовка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск единого сервиса (Бот + Веб-тренажёр)
```bash
python3 main.py
```
* Бот подключится к платформе MAX через Long Polling.
* Сервер веб-приложения запустится на `http://0.0.0.0:8080`.

### 3. Автономный запуск веб-сервера Mini App (без внешнего API мессенджера)
Если нужно протестировать только веб-тренажёр:
```bash
python3 webapp_server.py --port 8080
```
Интерфейс откроется в браузере по адресу: `http://localhost:8080`.

### 4. Автономный CLI-симулятор (консольный режим)
Позволяет протестировать весь диалоговый сценарий бота прямо в терминале:
```bash
python3 main.py --cli
```

## 📋 Пошаговый сценарий проверки для жюри

### Сценарий 1: Интерактивный Web App (Рекомендуется)
1. Откройте в браузере локальный адрес `http://localhost:8080` (или перейдите по ссылке туннеля).
2. **Вкладка «Тренажёр»:**
   * В центре экрана отображается карточка с чистой формулой (например, `(9 + x)²` или `(x - 4)(x + 4)`).
   * Попробуйте ввести ответ с клавиатуры компьютера или используя встроенные кнопки `x²`, `x³`, `x`, `y`, `+`, `-`.
   * Попробуйте ввести `x2 - 16` — строка автоматически отформатируется в красивый `x² - 16`.
   * Нажмите **«Проверить ответ»** — мгновенно отобразится результат и увеличится серия побед (Стрик).
   * Нажмите **«Показать подсказку формулы»** при затруднении.
3. **Вкладка «Статистика»:**
   * Проверьте динамику успеваемости: количество решённых задач, процент верных ответов, уровень мастерства и историю ответов.
4. **Вкладка «Учителю»:**
   * Нажмите **«Составить план урока (45 мин)»** — сгенерируется структурированный тайминг и разминка.
   * Нажмите **«Сгенерировать вариант из 15 задач»** — сформируется готовая контрольная работа с ключами ответов.
   * Кнопка **«Скопировать»** перенесёт текст в буфер обмена.
5. **Вкладка «Формулы»:**
   * Интерактивный справочник всех 30 формул курса с поисковой строкой.
   * Клик по любой формуле сразу открывает соответствующую задачу в тренажёре.

### Сценарий 2: Чат-бот в MAX Messenger
1. Откройте диалог с `@t594_hakaton_max_bot`.
2. При первом открытии бот автоматически отправляет интерактивное приветствие `/start`.
3. Нажмите кнопку **«🚀 Открыть тренажёр»** — запустится Mini App.
4. Нажмите **«📝 Решить задачу»** (`/task`) — бот пришлёт задачу прямо в чат.
5. Отправьте ответ в свободной форме (например, `x^2 - 9`, `x2 - 9` или `x в квадрате - 9`).
6. Используйте команду `/stats` для просмотра прогресса в текстовом виде с графическим баром.
7. Используйте команду `/lesson` для отправки методического конспекта в чат.

## 🧪 Автоматические тесты

В проекте реализовано **35 автоматических тестов**, покрывающих 100% критической бизнес-логики:
