# Чат-бот «Образовательные решения» (MAX Messenger)

Интеллектуальный помощник для школьников 7 класса и учителей математики в мессенджере **MAX**.
Проект разработан в рамках всероссийского хакатона **«Образовательные решения»** (Минобрнауки России / MAX / VK).

* **Чат-бот в MAX:** `@t594_hakaton_max_bot` («Хакатон МАХ 594»)
* **Репозиторий:** `git@github.com:BugFix-develop/MAX-BOT.git`

---

## 🎯 Назначение решения

Сервис помогает школьникам 7 класса отработать и закрепить навык применения **30 формул сокращенного умножения (ФСУ)**, а учителям — моментально сформировать методический план урока на 45 минут с готовыми заданиями и ответами.

### Ключевые возможности:
1. **Генерация уникальных задач** по 30 шаблонам ФСУ (разность квадратов, квадрат суммы/разности, кубы) с автоматическим исключением повторов.
2. **Интеллектуальный математический валидатор**: понимает степени (`x^2`, `x**2`, `во 2`, `в квадрате`), различные формы умножения (`4x`, `4*x`), нивелирует опечатки и автоматическую русскую раскладку (`х` $\to$ `x`).
3. **Личная статистика успеваемости**: фиксация количества попыток, процента точности и персональных рекомендаций.
4. **Методический конструктор планов уроков (45 мин)**: тайминг, теория, задачи для устного опроса, работы у доски, дифференцированных заданий и домашней работы с готовой шпаргалкой ответов для преподавателя.

## ⚙️ Переменные окружения (`.env`)

Создайте файл `.env` в корневой директории на основе шаблона `.env.example`:
```env
MAX_BOT_TOKEN=your_bot_token_here
MAX_API_BASE_URL=https://platform-api2.max.ru
DB_PATH=math_bot.db
```

* `MAX_BOT_TOKEN` — токен авторизации бота, выданный на платформе MAX.
* `MAX_API_BASE_URL` — базовый URL Bot API мессенджера MAX (`https://platform-api2.max.ru`).
* `DB_PATH` — путь к локальному файлу базы данных SQLite (по умолчанию `math_bot.db`).

## 🐳 Запуск через Docker (Рекомендуемый способ по регламенту хакатона)

Запуск всех компонентов решения одной командой:
```bash
docker compose up --build -d
```

Просмотр логов работы бота:
```bash
docker compose logs -f
```

Остановка решения:
```bash
docker compose down
```

## 📋 Пошаговый сценарий проверки пользователем

1. **Запуск и главное меню:** Откройте чат с ботом в мессенджере MAX (`@t594_hakaton_max_bot`). При открытии чата или нажатии «Запустить» бот **автоматически отправляет приветствие `/start`** с кратким путеводителем по тренажёру.
2. **Меню быстрых команд MAX:** Введите знак `/` в строке ввода мессенджера — отобразится нативное всплывающее меню со всеми доступными командами и пояснениями.
3. **Решение задач (`/task`):** Бот сгенерирует математическую задачу по формулам сокращенного умножения (например, `(x - 5)(x + 5)` или `(2x + 3)^2`).
4. **Проверка ответа:** Введите ответ в любом виде: `x^2 - 25`, `x**2 - 25`, словами `x в квадрате - 25` или с русской буквой `х` — умный валидатор распознает ввод, выдаст мгновенную оценку и мотивационный комментарий.
5. **Личная статистика (`/stats`):** Наглядный отчет об успеваемости с графическим прогресс-баром (`🟩🟩⬜⬜`), процентом точности и присвоенным уровнем (Эксперт / Практик / Ученик).
6. **План урока для учителей (`/lesson`):** Генерация структурированного 45-минутного плана урока, оптимизированного под экраны смартфонов (двухстрочный карточный формат формул с надстрочными индексами `x²` и шпаргалкой для учителя).
7. **Справка по вводу (`/help`):** Памятка с примерами степеней, коэффициентов и раскладок клавиатуры.
8. **Отмена действия (`/cancel`):** Сброс текущей задачи и мгновенный возврат в главное меню.
